# Real-Time Risk & Anomaly Intelligence Platform

A streaming pipeline that detects abnormal behaviour — volatility spikes,
fraud, operational incidents, latency blowouts, corrupted data — end to end,
in real time, with measured (not claimed) detection quality and bounded
ingestion→alert latency.

Two synthetic domains run through the *same* pipeline simultaneously, so the
platform is deliberately legible to more than one audience:

| Audience | What they see here |
|---|---|
| **Quant / trading** | Market-microstructure risk monitoring: spread, realized volatility, order imbalance, regime-change detection |
| **Banking / fintech** | Transaction fraud & anomaly monitoring: decline rate, velocity, amount anomalies |
| **AI / ML** | A complete, evaluated ML pipeline: statistical + unsupervised + supervised ensemble, explanation, drift detection, precision/recall against held-out ground truth |
| **Platform / infra** | Rust ingestion + stream processing, Kafka-API streaming, columnar storage, Prometheus/Grafana observability |
| **Consulting / product** | A visible business problem (bad things happen in data streams; find them fast, explain them, don't cry wolf) with a working demo |

## Architecture

See [`ARCHITECTURE.md`](ARCHITECTURE.md) for the full system diagram and the
rationale behind every major technical choice.

```
WebSocket (synthetic data-generator, ground-truth-labeled)
        ↓
  Ingestion (Rust, tokio + rdkafka)
        ↓
  Redpanda (Kafka API): raw-events
        ↓
  Feature service (Rust): rolling windows → features topic + ClickHouse
        ↓
  ML inference (Python): statistical + ML ensemble → anomaly score, explanation, drift
        ↓
  Redpanda: alerts, model-metrics  →  ClickHouse
        ↓
  API gateway (FastAPI) → React dashboard
```

## Repository layout

```
services/
  data-generator/   Python  — synthetic WS data source + anomaly injection (ground truth)
  ingestion/        Rust    — WS client → validate → Kafka producer
  feature-service/  Rust    — Kafka → windowed features → Kafka + ClickHouse
  ml-inference/     Python  — statistical detectors, ML ensemble, drift, rules engine
  api-gateway/      Python  — REST/WS API for the dashboard
  dashboard/        React/TS — operator UI
infra/              docker-compose services: Redpanda, ClickHouse, Prometheus, Grafana
schemas/            JSON Schema copies of docs/data-contracts.md, enforced in CI
docs/               architecture, data contracts, metrics, runbook, benchmarks
tests/
  integration/      end-to-end pipeline tests against docker compose
  eval/             precision/recall/drift evaluation harness
scripts/            replay, load test, drift injection, demo helpers
```

## Quickstart

```bash
make up          # docker compose up: redpanda, clickhouse, prometheus, grafana
make bootstrap    # create topics + apply clickhouse schema
make demo         # start all services + open the dashboard
make eval         # run the labeled-scenario precision/recall/drift report
make down
```
